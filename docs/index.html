The Problem

Your documents live in SharePoint.
Your AI can't see them.

Most SharePoint-to-RAG pipelines are welded to one company's internal index and identity stack. Rebuilding that plumbing for every project is where the weeks go.

🔒

Locked-in pipelines

Existing solutions hard-wire a single proprietary vector index and auth provider. You can't reuse them.

🔁

Full re-scans

Naive indexers reprocess everything on every run — slow, expensive, and hammering the Graph API.

☁️

Cloud-heavy

Most require standing up managed infrastructure before you can index a single file.

How It Works

From SharePoint to answer,
in four steps.

Event-friendly, incremental, and idempotent. Run sync on a schedule — only changed files are touched.

1

Connect

App-only Microsoft Graph auth (MSAL). No signed-in user, no interactive login.

2

Delta sync

Folder-scoped Graph delta API pulls only what changed — with expired-cursor auto-reset.

3

Extract & embed

PDF/DOCX/PPTX/HTML/MD → clean text → token-aware chunks → vectors.

4

Query

Retrieve the most relevant chunks and answer with citations via your LLM backend.

Features

Everything reusable,
nothing vendor-specific.

~80% of a SharePoint RAG stack is generic plumbing. This extracts it and puts the rest behind clean interfaces.

🔑

Headless auth

Microsoft Graph app-only (client credentials) with retry/backoff and token refresh.

⚡

Incremental sync

Folder-scoped Graph delta with HTTP 410 expired-cursor recovery. Only changed files reprocess.

🧬

Change lifecycle

Detects create / update / rename / move / delete with SHA-256 content dedupe.

📄

Multi-format

PDF, DOCX, PPTX, HTML, Markdown, TXT, CSV, JSON extraction out of the box.

🔌

Pluggable backends

Swap embeddings, vector store, or LLM without touching the pipeline.

🩺

doctor command

One-shot auth + permission check that lists visible files — validate setup in seconds.

💻

CLI-first

init, sync, query, status, doctor — scriptable and cron-friendly.

🧪

Tested

42 tests, mocked at the boundary. CI across Python 3.9–3.12. Runs fully offline.

🏠

No lock-in

Local state + local vector store by default. No AWS, no managed service required.

Quickstart

Index your first site
before your coffee's cold.

Register an Entra app (one time), drop three values into .env, and go. The doctor command confirms auth before you index anything.

🔑 Graph app-only 🧠 Azure OpenAI embeddings 🗄️ Local vector store 💬 gpt-5-chat answers
terminal
# install
pip install -e ".[all]"

# validate auth (indexes nothing)
sp-rag doctor --site-url "https://contoso.sharepoint.com/sites/Research" \
  --folder "Knowledge Base"

# index and query
sp-rag init --site-url "…" --folder "Knowledge Base"
sp-rag sync
sp-rag query "What is our data retention policy?"
